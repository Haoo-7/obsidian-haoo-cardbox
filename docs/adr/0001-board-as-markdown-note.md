# 自建画板，画板存成一篇 Markdown 笔记

画板不交给 Obsidian 原生 Canvas，而是插件自己实现。原因是双击翻面、拿起倾斜、按缩放程度切换卡片显示内容、整卡染色的小卡和画笔，原生 Canvas 要么做不到，要么只能依赖它未公开的内部接口。每块画板存成一篇 Markdown 笔记，做法和 Excalidraw 插件一样：正文是自动生成的 MOC（一串 `[[卡片]]` 链接），末尾一个代码块存画板数据，所以反向链接、关系图谱、搜索、同步都能直接用。数据块的字段名沿用 JSON Canvas（`nodes`、`edges`、`x`、`y`、`file`），笔迹放在额外的 `strokes` 字段里，以后导出成 `.canvas` 时只会丢掉笔迹。

## Considered Options

- **插件只做归堆和摊开，生成原生 `.canvas`**：工作量小，但上面列出的交互做不到，而且原生 Canvas 没有画笔。
- **直接存成 `.canvas` 文件**：笔迹只能放在自定义字段里，被原生 Canvas 编辑保存后，这些字段可能会丢。
- **存进插件的 `data.json`**：库里看不到画板，没有反向链接，换设备时也容易丢。
